so this is basically a terminal interface to log items with date and time .
   
to install :  
  
```bash  
chmod +x install.sh  
./install.sh  
```

usage :   
   
```bash  
mylogger 
```
   
save with current date or choose a different date . everything will be at ~/logs/  where the name of the file is the current date of the day ex: 12sep2026.txt
